Human Mechanic - متجر المستلزمات الطبية
=====================================

المجلد: C:\Users\dell\OneDrive\Documents\human-mechanic

طريقة التشغيل:
1- افتح ملف index.html مباشرة بالضغط المزدوج (يعمل بدون سيرفر لأنه يعتمد على localStorage)
2- أو شغّل سيرفر محلي: اسحب المجلد إلى VS Code ثم استخدم Live Server

مكونات المشروع:
- index.html : واجهة المتجر الرئيسية (Hero, أقسام, منتجات, بحث, تواصل, سلة)
- css/style.css : تصميم حديث متجاوب بالكامل (موبايل/تابلت/ديسكتوب)
- js/db.js : طبقة قاعدة البيانات الديناميكية (localStorage) - لا يوجد منتجات ثابتة في HTML
- js/app.js : منطق المتجر (بحث، سلة، واتساب، ديناميكية)
- admin/index.html : لوحة الإدارة المحمية
- css/admin.css : تصميم لوحة الإدارة
- js/admin.js : منطق الإدارة مع حماية حقيقية

بيانات الدخول الافتراضية للوحة الإدارة:
- الرابط: admin/index.html أو من المتجر عبر القائمة ⋮ > لوحة الإدارة
- اسم المستخدم: admin
- البريد: admin@human-mechanic.com
- كلمة المرور: admin123
(يمكن تغييرها من "إعدادات الحساب" داخل اللوحة - محمية بكلمة المرور الحالية)

المميزات المنفذة:
✓ 3 أقسام: العلاج الطبيعي / الصيدلة / الأسنان (فلترة فورية)
✓ منتجات ديناميكية 100% من DB (إضافة/تعديل/حذف من الأدمن)
✓ كل منتج: صورة، اسم، سعر، وصف، تفاصيل، كلمات بحث، كمية، اطلب الآن
✓ بحث احترافي فوري في الاسم والوصف والقسم والكلمات (عربي/إنجليزي) + رسالة "لم يتم العثور..."
✓ قائمة علوية: شعار HM + بحث + سلة + قائمة ⋮ (الرئيسية/الأقسام/تواصل/الإدارة)
✓ تواصل ديناميكي: الأدمن يضيف أي منصة (واتساب/فيسبوك/انستا/تيك توك...) والأيقونة تظهر تلقائياً + تفعيل/إخفاء/ترتيب
✓ الطلب عبر واتساب: رقم ديناميكي من الإعدادات + رسالة منظمة (منتج واحد أو سلة كاملة برسالة واحدة)
✓ سلة مشتريات كاملة مع تجميع المنتجات
✓ لوحة إدارة محمية بـ Authentication حقيقي (sessionStorage) + منع الوصول بدون دخول
✓ إعدادات الحساب: تغيير اسم المستخدم/البريد/كلمة المرور (يتطلب كلمة المرور الحالية)

ملاحظات:
- جميع البيانات تُحفظ في localStorage (يمكن استبدالها لاحقاً بـ Firebase/Supabase بسهولة)
- التصميم متجاوب 100% وتم اختباره على أحجام مختلفة
- لا يوجد أي منتج أو رقم واتساب ثابت في الكود — كل شيء ديناميكي من DB
